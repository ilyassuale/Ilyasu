# Interview AI Frontend

React/Next.js single-page application.

## Wireframes

1. **Login/Register**: Email/password and Google sign-in.
2. **Upload Resume**: Drag-and-drop PDF/DOCX/TXT upload.
3. **Resume Dashboard**: Parsed resume, ATS score, missing skills, recommended roles.
4. **Job Matches**: Top 10 matching roles with confidence.
5. **Interview Setup**: Select difficulty, categories, job role.
6. **Interview Room**: Webcam/mic, question display, voice/text answer input.
7. **Report**: Overall score, section scores, strengths, roadmap, courses.
8. **Recruiter Dashboard**: Candidate search, reports, analytics.
9. **Admin Dashboard**: User management, job management, analytics.

## Implementation

The frontend can be built with Next.js + Tailwind CSS + React Query. See `package.json` for dependencies.
